## 主要功能

- **报纸版面**：工具条、完整／紧凑报头、双耳、简报、长读、侧栏及本期要目。
- **长文阅读**：本地衬线字体、引用、脚注、表格、目录、代码与图表展开／折叠。
- **公式与图表**：按内容加载 KaTeX、Mermaid、highlight.js，失败时保留可读回退。
- **媒体回退**：失效图片／视频替换为本地作品图，保留作品名、alt 和提示，不新增“作品介绍”外链。
- **Markdown**：原文存档、复制和 REST 单篇导出，保留权限、nonce、导出开关与可见性边界。
- **机器可读内容**：`/llms.txt` 索引与 `/llms-full.txt` 全量全文，可在「外观 → llms.txt 设置」中开关、选内容来源（自动生成／部分手动／全部手动）并控制全量的篇数与摘要口径；另有 SEO/schema 输出与既有 SEO 插件让位机制。
- **广告位**（外观 → 广告位）：首页横幅、文章页侧栏（桌面端专属，随悬浮目录）与「读者来信」上方三处槽位；占位图按桌面/平板/手机端分别配置（媒体库选图、分端开关与独立跳转链接）；后台填入广告代码后按受信管理员内容输出，加载失败可配置换回占位图或整块不输出。出厂为占位形态，主题不内置任何广告代码。
- **默认邮件样式**：出站邮件自动套用朴素表格布局并附纯文本降级；检测到其他邮件模板插件时整体让位。
- **国际化**：全部用户可见 PHP 文本可经 gettext 翻译（文本域 `paddysun-newsprint`），随包附 `.pot` 模板与英文翻译包；英文站点（en_US）前台与后台设置页开箱即英文，中文站点输出不变。
- **阅读动线**：文章页悬浮目录贴近正文右缘、默认收起。
- **档案馆与版签总目**：可指定给页面的「档案馆」模板（栏目导览网格 + 热门版签与月度字数条状图 + 按年分组的全量文章年历，滚动懒渲染）与「版签总目」模板（按一级分类分组的标签索引）；版签统一半透明圆角底，桌面/平板/手机自适应。
- **CDN 友好**：匿名公开视图输出标准 `Cache-Control`（`s-maxage` + `stale-while-revalidate`）与 `Last-Modified`（支持 304），登录态/评论者/带查询串请求自动直通；配合 EdgeOne 等「遵循源站」的 CDN 即可整页缓存。索引页结果层走 transient 缓存（启用 Redis Object Cache 时即 Redis），取数批量化、多语言（Polylang/WPML）自动退回 WP API 路径。

SEO/schema、Markdown 存档与 REST、llms 是保留的产品功能，不需要另装强制插件。本轮为自主分发，不是 WordPress.org 上架版本或官方审核通过声明。

## 1.1.2 更新

- **修复：发文后的新评论对老访客不可见。** CDN 边缘缓存头的 `Last-Modified` 此前只取全站文章修改时间的最大值，而评论不改动文章本身——发文后该验证时间静止，老访客的条件请求被无限 `304`，浏览器一直持有发文瞬间的页面快照（表现为「没有评论区」）。现验证时间纳入最新已批准评论时间与单调内容戳记（随发文/评论/词表事件推进、只增不减），评论入库即刷新验证时间，条件请求立即返回 200 与新内容。
- 新发布 24 小时内的文章 `s-maxage` 降至 60 秒（新文评论热流量即时生效），之后恢复 600 秒；`paddysun_ns_fresh_window` 过滤器可调窗口。
- 已受影响浏览器的自愈：升级 1.1.2 后无需任何操作——新的验证时间已晚于旧快照的 `If-Modified-Since`，下一次刷新即返回 200 全量内容。

## 1.1.1 更新

- **修复站点编辑器报「区块包含未预料的或无效的内容」**：在站点编辑器中打开「档案馆」「版签总目」模板时，两个索引区块模式的主体输出（无区块定界注释的裸 HTML）无法通过编辑器的区块校验。现主体输出包入 `core/html` 区块封套——前台输出逐字节不变、编辑器解析合法（已在隔离站编辑器复现并验证清零）。前台渲染与既有功能不受影响。
- 主题更新/切换时自动推进索引缓存版本（`after_switch_theme`），升级后旧格式 transient 立即失效重建，无需等待 TTL。
- 若 1.1.0 期间曾在站点编辑器保存过这两个模板：请删除数据库中的用户自定义模板副本（外观 → 编辑器 → 模板 → 已自定义），让模板回到随主题文件的最新版本。

## 1.1.0 更新

- **新增「档案馆」页面模板**（建议用于 /blog）：栏目导览（按文章数降序最多 16 个分类的 4 列网格，随视口 4→3→2→1 列并裁剪个数）+ 双栏「热门版签 × 月度字数」（近 24 个月纯 CSS 条状图，最新月在最右、悬停显示年月/字数/篇数，统计行按「/」分段自适应换行）+ 年历（按年份分组的全量文章，`content-visibility` 原生懒渲染）。
- **新增「版签总目」页面模板**（建议用于 /tags）：标签按一级分类分组（组内篇数降序），不属于任何栏目的归入「散签」；分组标题双实线与档案馆的单横线刻意区分。
- **性能三层优化**：索引结果 transient 缓存（固定键 + 版本失效，发文/词表变动即刷新）；直连 SQL 全批量化（版签总目 212→8 查询，档案馆 53→15，暖缓存 1-2 条）；年历瘦列取数不捞正文，`%author%`/`%category%` 固定链接结构实测可配。
- **CDN 边缘缓存头网关**：见上「CDN 友好」；与页面缓存/SEO 插件的头互让，`paddysun_ns_edge_cache` 过滤器可整体停用。
- **国际化补全**：23 条新增可译字符串入 `.pot` 并补英文译文，en_US 站点档案馆/版签总目开箱英文；索引缓存键含 locale。
- **工程与安全**：独立 Agent 双重代码审查 + Theme Check（0 REQUIRED/0 WARNING）+ 渗透测试（36 项探测，XSS/SQLi/缓存投毒/越权/CSRF 面全过，报告见 RELEASE-1.1.0.md）；`repair-footnotes.php` 移出主题包（保留在仓库 `tools/` 目录）；PHP 7.4 兼容性修复与一批编码卫生清理。
- 官方主题目录要求在本轮作为工程指引采用（暂不提交目录）；细节与取舍见 `RELEASE-1.1.0.md`。

## 1.0.2 更新

- **修复脚注（引用）**：列表项里的 `- [^id]: 文字` 定义行此前完全不被识别——文末列表只剩空序号、定义行标签被误转成重复角标、定义文字游离在正文中、重贴无限增殖。现支持段落/列表项/裸段落三种定义形态，标签不再误转；**已受损的文章升级后保存一次即自动修复**；角标完好但列表缺失的文章用随仓 `repair-footnotes.php` 配合「原文 MD」重建。
- **修复行内徽章排版**：shields.io 徽章等插在段落文字中间的图片不再被全局插图规则块级化——保持行内、垂直居中、原始大小、可并排；独立图片块排版协议不变。
- 细节与取舍（如正文引用紧跟半角冒号保持字面）见 `RELEASE-1.0.2.md`。

## 1.0.0 更新

- 修复首页文章卡片正文缺失：正文为单个 HTML 块（手工 HTML 粘贴形态）的文章，首页侧栏摘录回退到经典段落提取，沿用侧栏既有预算与剔除规则；主稿、简报、单篇页输出不变。
