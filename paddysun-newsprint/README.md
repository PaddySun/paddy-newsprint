# Paddysun Newsprint 0.10.11

报纸风格中文 WordPress 块主题。此目录是可安装的主题文件，目录名应保持 `paddysun-newsprint`。

## 安装

把本目录上传至 WordPress 的 `wp-content/themes/`，或把整个本目录压缩为 ZIP 后在「外观 → 主题 → 上传主题」安装。不要把带额外根目录的 GitHub 仓库 ZIP 直接当作主题包上传。

环境：WordPress 7.1+；实际验证 PHP 8.3.30，建议 PHP 8.3+。元数据声明的 PHP 7.4 最低兼容性尚未完成运行矩阵验证。

首页包含三栏头条、订阅与分类要目；近期文章卡片流、友链网格和徽章墙样板已移除。关于页样板保留简介和时间线。提醒确认弹窗默认不挂载，编辑器中使用普通核心区块，前台才增强为 dialog。

公开版的页脚、外链按钮、作品清单采用示例内容。上线前替换占位链接、备案说明和 artwork-fallbacks.json 的示例配对。用户自行加入的内容图片与插件仍可能产生外部请求。

功能、资源许可和版本历史见 `readme.txt`。完整操作与安全说明见发布仓库根的 `操作手册.md`、`SECURITY.md`；独立主题 ZIP 不包含这些根文档。

编辑器提醒部件保存流程及所有插件组合尚不能视为全面验收通过；升级前先在测试站验证，保留数据库模板部件定制内容。
