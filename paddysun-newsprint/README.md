# Paddysun Newsprint

报纸风格的 WordPress 块主题。首页以报头、双耳、三栏主稿和本期要目组织内容，文章页提供暖纸色板、三线表格、代码和图表阅读增强。

当前源码版本：**0.10.13**。源码版本不代表已发布、已通过视觉验收或已获 WordPress.org 审核。

## 安装与内容边界

使用公开安装包 `paddy-newsprint-<version>.zip`；包内主题目录和 text domain 保持 `paddysun-newsprint`。仓库下载 ZIP 不等于可直接安装的主题 ZIP。

- WordPress 7.1+；PHP 7.4+ 为当前声明，PHP 7.4 运行兼容性须单独验证。
- 导航使用核心导航区块；报头、页脚、订阅框在站点编辑器中调整。
- 首页主稿显示文章的特色图片。全新空站没有个人照片并非漏打包，不会自动导入作者媒体库。
- 七张本地失效回退图只用于符合条件的正文图片/视频失败处理，不是默认首页图库。图片与作品标题固定配对，前端不提供作品介绍外链；来源与许可仍见 `readme.txt`。
- 备案和服务状态是明确标注的编辑占位内容，不是主题提供的真实备案或服务监控。启用后按站点实际情况替换或移除。
- 按钮墙使用本地抽象占位图及本站链接，交换前须换成已授权资源和准确替代文字。

## 功能

- 区块模板、模式、theme.json 样式令牌及样式变体。
- 按内容加载 KaTeX、Mermaid 和 highlight.js；长代码、长图表和移动端宽表可展开。
- 本地字体、图标和回退图，不热链主题图片；文章自行插入的外链及站点插件不属于“主题自身资产零外部请求”的承诺。
- 评论字段样式及本地头像；不绕过核心或插件 URL 校验。
- SEO/schema、Markdown 原文存档与 REST 导出、llms 索引及全文导出是本主题保留的产品功能；保留权限、可见性、导出设置和 SEO 插件共存边界。llms 的开关、内容来源（自动/部分手动/全部手动）、全量篇数与摘要口径在「外观 → llms.txt 设置」中设置，关闭的端点返回 403。本轮为自主分发，不开展 WordPress.org 上架工作线。
- 提醒部件使用普通核心区块供编辑，前台按需包装；后台、REST 和 Feed 不增强。

## 0.10.13 验证边界

0.10.13 为 llms 设置页（外观 → llms.txt 设置）：`/llms.txt` 总开关、总开关开启时的 `/llms-full.txt` 独立开关、三种内容来源（两个文本框按所选模式出现、带中英双语格式提示、切模式不丢内容）、全量篇数与摘要/全文口径，以及 llms.txt v2 的 `rel="describedby"` 广播。关闭态返回 403 且不缓存；全量端点关闭时不再在索引里推荐它。

**全量正文默认关闭**：`/llms-full.txt` 装好后先返回 403，需在设置页勾选后才输出——这是相对 0.10.12 的**有意变更**（原先默认直接输出全文），升级站如需保留该地址须手动开启。`/llms.txt` 默认保持开启。

除全量开关外，其余默认值与 0.10.12 一致：把设置调成「索引开 + 全量开 + 自动 + 100 篇 + 全文」后，两个端点的输出与 0.10.12 逐字节相同（该结论由隔离站实测支撑，见开发仓库 `docs/paddy-newsprint-0.10.13-llms/final.md`）。

0.10.12 的局部修复（长站名收缩、表头换行、手机页脚对齐和状态点、正式公开 URI、七组作品配对与子目录图片 URI）保持不变；其静态、单测及隔离运行结果在开发仓库 `docs/paddy-newsprint-0.10.12-handoff.md`。不要执行旧个人站默认路径的发布命令来验证此公开树。发布工具仅接受公开输入，输出到独立的新目录，候选 ZIP 必须通过单独的发布门。

数据库内已定制的模板不会被主题升级自动覆盖。源码中的状态点存在，不表示线上数据库模板中也存在；线上差异需要独立核对。
